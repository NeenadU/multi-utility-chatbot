# Multi Utility Chatbot

An AI-powered chatbot built using Streamlit, LangChain and LangGraph.

## Features
- PDF Question Answering using RAG
- PDF ingestion and document processing
- Hugging Face embeddings
- FAISS vector database
- LangGraph conversational workflow
- Conversation history and thread management
- Web search
- Calculator
- Stock price retrieval

## Tech Stack
- Python
- Streamlit
- LangChain
- LangGraph
- Groq LLM
- Hugging Face
- FAISS
- SQLite

## Run Locally

1. Clone the repository.
2. Install dependencies using: pip install -r requirements.txt
3. Create a .env file with your API keys.
4. Run: python -m streamlit run chatbot_frontend.py

## Environment Variables
- GROQ_API_KEY
- ALPHAVANTAGE_API_KEY

Never upload API keys or private documents to GitHub.
